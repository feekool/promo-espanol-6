⚡ Как запустить тёмный форум за 1 минуту

  1. 1. GitHub аккаунт Создай профиль на github.com (бесплатно)
  2. 2. Шаблон Перейди: github.com/feekool/feekool.github.io
  3. 3. Копируй Нажми "Use this template" → "Create a new repository". Назови, например, "portugues-dark"
  4. 4. GitHub Pages Settings → Pages → ветка main → Save. Через 30-60 сек форум онлайн!
  5. 5. Настрой Открой `theme.css` → переключи переменные на тёмные. Готово. Пригласи учеников.
💡 Pro tip: Хочешь кастомную тёмную тему под свой бренд? Напиши в Issues — соберём персональный CSS.

💡 Почему тёмный режим ускоряет обучение

🌙

Меньше усталости

Снижает нагрузку на глаза при вечерних занятиях. Мозг сохраняет энергию на запоминание, а не на борьбу с ярким светом.

🔍

Фокус на контенте

Тёмный фон убирает визуальный шум. Текст, аудио-кнопки и грамматические таблицы выделяются четче.

⚡

Быстрая загрузка

Тёмные интерфейсы требуют меньше графических ресурсов. Форум грузится мгновенно даже на 3G.

📱

Экономия батареи

На OLED-экранах тёмные пиксели отключены. Ученики могут практиковаться дольше без подзарядки.
